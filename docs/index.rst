Overview
--------

AI-Film-Studio is a production-oriented platform for AI-assisted film production. It separates the SaaS control plane from film-scoped runtime infrastructure and AI inference.

The documentation covers local development, AI model configuration, service responsibilities, job execution, AWS deployment, security, operations, testing, and troubleshooting.
